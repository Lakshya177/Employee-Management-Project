# Employee-Management-Project (Java Swing + JDBC)
📌<bold>Introduction</bold>
<br>
The Employee Management System is a desktop application developed using Java Swing and JDBC. The system helps an organization manage employee records such as adding, updating, deleting, and viewing employee details. The system automatically generates Employee ID and validates user input data.git
<br>
🎯<bold>Objective</bold>
The main objective of this project is to develop a desktop-based application to manage employee records efficiently and to understand Java GUI and database connectivity using JDBC.
